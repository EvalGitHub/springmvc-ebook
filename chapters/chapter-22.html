4、@RequestHeader

@RequestHeader是将请求头信息和控制器方法的形参创建映射关系

@RequestHeader注解一共有三个属性：value、required、defaultValue，用法同@RequestParam

    @RequestMapping("/getUserInfo3")
    public String getUserInfo3(
            @RequestParam(value="id_", required = false, defaultValue = "1") Integer id,
            @RequestParam(value="user_name") String user,
            @RequestHeader(value="host", required = true, defaultValue = "localhost:8080") String host
            ) {
        System.out.println(user+ " " + id + " " + host);
        return "userInfo";
    }

// http://localhost:8080/springMvc/getUserInfo3?id_=111&user_name=test
